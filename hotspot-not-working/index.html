Mobile hotspot not working

A hotspot shares the phone's own mobile data. So first make sure the phone itself has working mobile data, then look at the hotspot's band and password.

What you seeThe laptop cannot find or join the hotspot, or joins and shows "No internet"

1. Does the phone itself have internet on mobile data?

Turn Wi-Fi off on the phone and open a website. If that fails, fix mobile data first: see mobile data not working. A hotspot cannot share what the phone does not have. Note that a phone connected to Wi-Fi does not normally share that Wi-Fi through its hotspot; the hotspot uses mobile data.

2. Turn the hotspot on properly

  • Android: Settings › Network & internet › Hotspot & tethering › Wi-Fi hotspot › on. Samsung: Settings › Connections › Mobile Hotspot and Tethering.
  • iPhone: Settings › Personal Hotspot › Allow Others to Join on. Keep this screen open while the other device connects the first time: an iPhone's hotspot is easier to find while the screen is showing.

Note the network name and password shown there. On iPhone the hotspot's name is the phone's name (Settings › General › About › Name); a name with unusual symbols or emoji can confuse some laptops, so keep it simple.

3. The other device cannot see the hotspot

  • Band. Many phones broadcast the hotspot on 5 GHz by default, which older laptops, printers and TVs cannot see. Android: Hotspot settings › Band (or "AP band") › choose 2.4 GHz, or turn on "Extend compatibility". iPhone: Personal Hotspot › Maximise Compatibility on.
  • Hidden network setting off.
  • Turn the hotspot off and on; restart both devices.
  • On the laptop, switch Wi-Fi off and on to refresh the list.

4. The other device sees it but cannot join

  • Password. Retype it; set a simple new one of at least eight letters and digits to rule out mistakes.
  • Forget the hotspot on the laptop or other phone and join afresh, especially if you changed the password or the phone.
  • Security type. Android: Hotspot › Security › WPA2-Personal (some devices cannot join WPA3).
  • Device limit. Android: Hotspot › check the maximum number of connections and any "allowed devices only" setting.

5. Joined, but no internet

  1. Check step 1 again: mobile data working on the phone.
  2. Data Saver / Low Data Mode off on the phone. Android's Data Saver blocks hotspot use.
  3. Battery Saver / Low Power Mode off: they can suspend the hotspot.
  4. VPN off on the phone.
  5. APN. Some operators use a separate setting for tethering. Android: SIMs › Access Point Names › Reset to default. Ask the operator if hotspot use is included in your plan; a few plans restrict it.
  6. On the laptop: forget and rejoin; set IP and DNS to automatic; turn off its VPN. See our sister site's Wi-Fi connected but no internet for Windows.
  7. Daily data finished. The hotspot stops with it.

6. The hotspot keeps turning off

  • Android: Hotspot settings › turn off Turn off hotspot automatically (when no devices are connected).
  • Keep the phone on charge: hotspot use drains the battery fast and warms the phone, and a hot phone shuts the hotspot down. See phone overheating.
  • iPhone: the hotspot sleeps when nothing is connected; open the Personal Hotspot screen to wake it.

7. Other ways to share

  • USB tethering is the most reliable and charges the phone at the same time. Connect by cable; Android: Hotspot & tethering › USB tethering. iPhone: connect by cable and tap Trust; Windows may need the Apple Devices app or iTunes installed.
  • Bluetooth tethering is slow but light on battery.

8. Reset network settings

If nothing else works: Android Settings › System › Reset options › Reset Wi-Fi, mobile & Bluetooth. iPhone Settings › General › Transfer or Reset iPhone › Reset › Reset Network Settings.

Keep the hotspot safe and cheap

Use a password, never an open hotspot. Laptops treat a hotspot like ordinary Wi-Fi and may download large updates over it: on Windows, set the connection as metered (Settings › Network & internet › Wi-Fi › the network › Metered connection). Turn the hotspot off when finished.

Why can my laptop not see my phone's hotspot?

Most often the hotspot is on the 5 GHz band and the laptop supports only 2.4 GHz. Switch the band or turn on the compatibility option.

Does using a hotspot cost extra?

It uses your normal mobile data allowance, usually faster than phone use alone, because computers download more.

For Android phones and iPhones. Written in November 2026 for Android 13 to 15 and iOS 17 and 18. Phone makers rename menus; use the search box in Settings if a name differs. Back up before any reset.
