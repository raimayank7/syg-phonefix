Mobile data not working

If calls work and data does not, the cause is the plan, a setting on the phone, or the access point (APN) settings.

What you seeThe 4G or 5G symbol shows but pages do not load, or the symbol is missing

1. The basics

  1. Mobile data is on. Swipe down and check the Mobile data tile. Android: Settings › Network & internet › SIMs › the SIM › Mobile data. iPhone: Settings › Mobile Service › Mobile Data.
  2. Flight mode on for ten seconds, then off.
  3. Restart the phone.
  4. Wi-Fi off for the test, so that the phone is not clinging to a Wi-Fi network with no internet.

2. Is the plan used up?

The commonest cause. When the day's data allowance is finished, operators either stop data or cut the speed so low that nothing loads. Check the balance in the operator's app or with the balance-check code your operator publishes. A recharge that has expired, or a postpaid bill past due, does the same.

3. The right SIM for data (dual-SIM phones)

  • Android: Settings › Network & internet › SIMs: check which SIM is set for Mobile data. Samsung: Settings › Connections › SIM manager › Mobile data.
  • iPhone: Settings › Mobile Service › Mobile Data: choose the line.

4. A data limit or saver on the phone

  • Android: Settings › Network & internet › SIMs › the SIM › Data warning & limit: if "Set data limit" is on and reached, data stops. Raise or turn off the limit. Also check Data Saver is off.
  • iPhone: Settings › Mobile Service: scroll down the app list; an app with its switch off cannot use mobile data. Low Data Mode is under Mobile Data Options.

5. Network type

Settings › SIMs › Preferred network type (Android) or Mobile Data Options › Voice & Data (iPhone). Choose the automatic 5G/4G option. In areas where 5G is weak, choosing 4G/LTE gives a steadier connection.

6. Roaming

Outside your home state or abroad, data may need Data roaming switched on: Android SIMs › Roaming; iPhone Mobile Data Options › Data Roaming. Within India, national roaming normally works without extra steps; abroad, data roaming can be very costly without an international pack, so check with the operator first.

7. APN settings

The access point name (APN) tells the phone how to reach the operator's internet gateway. It is set automatically from the SIM, but can be lost after a reset, an update or a SIM change.

  • Android: Settings › Network & internet › SIMs › the SIM › Access Point Names. Tap the three dots › Reset to default. Samsung: Settings › Connections › Mobile networks › Access Point Names.
  • iPhone: APN is managed by the operator's settings; accept a Carrier Settings Update if offered (Settings › General › About).

If reset does not help, the operator's customer care or website gives the correct APN name to enter, or sends the settings by SMS.

8. Reset network settings

Android: Settings › System › Reset options › Reset mobile network settings. iPhone: Settings › General › Transfer or Reset iPhone › Reset › Reset Network Settings. Saved Wi-Fi passwords are forgotten.

9. Still nothing

  • Reseat the SIM and try it in another phone. See SIM not detected.
  • Turn off VPN and Private DNS: Android Settings › Network & internet › VPN, and Private DNS set to Automatic or Off. iPhone Settings › VPN.
  • Date and time automatic.
  • Update the system.
  • Ask the operator whether data is barred on the number or there is a local outage.

Data is on but slow

  • Check the signal bars and move to a better spot.
  • Busy hours on a crowded tower slow everyone; test late at night to compare.
  • After the daily allowance, speed is throttled.
  • Restart the phone to make it pick a different tower or band.
  • See whether one app is hogging data: Android SIMs › App data usage; iPhone Mobile Service list.

Only one app has no data

Android: Settings › Apps › the app › Mobile data & Wi-Fi › turn on Mobile data and Background data. iPhone: Settings › Mobile Service › the app's switch.

Why does it show 4G but nothing opens?

The phone is attached to the network, but the data session is not working: usually an exhausted pack, a wrong APN or a data limit.

Does resetting network settings delete my files?

No. It clears only Wi-Fi, mobile, Bluetooth and VPN settings.

For Android phones and iPhones. Written in November 2026 for Android 13 to 15 and iOS 17 and 18. Phone makers rename menus; use the search box in Settings if a name differs. Back up before any reset.
